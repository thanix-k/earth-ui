## Usage

```tsx
import { Calendar } from "@/components/ui/calendar"
```

```tsx
const [date, setDate] = React.useState<Date | undefined>(new Date())

<Calendar mode="single" selected={date} onSelect={setDate} />
```

The calendar reads the current date to mark today. In a Next.js app with `cacheComponents` enabled (the default for new apps), render it inside `<Suspense>` so that value is computed per request, not at build time:

```tsx
<Suspense>
  <BookingCalendar />
</Suspense>
```
