## Usage

```tsx
import {
  AlertDialog,
  AlertDialogAction,
  AlertDialogCancel,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogTitle,
  AlertDialogTrigger,
} from "@/components/ui/alert-dialog"
```

```tsx
<AlertDialog>
  <AlertDialogTrigger>Cancel appointment</AlertDialogTrigger>
  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogTitle>Cancel this appointment?</AlertDialogTitle>
      <AlertDialogDescription>The customer will get a cancellation email.</AlertDialogDescription>
    </AlertDialogHeader>
    <AlertDialogFooter>
      <AlertDialogCancel>Keep</AlertDialogCancel>
      <AlertDialogAction>Cancel appointment</AlertDialogAction>
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>
```

Unlike a dialog, it doesn't close when people click outside it.

Below 768px it opens as a bottom sheet with a close button, and its `data-layout` is `sheet` (`dialog` otherwise). Set `isSheetOnPhone={false}` on `AlertDialogContent` to keep it centred, or `showCloseButton={false}` when the content draws its own close button.
