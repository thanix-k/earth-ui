## Usage

```tsx
import {
  Sidebar,
  SidebarContent,
  SidebarInset,
  SidebarMenu,
  SidebarMenuButton,
  SidebarMenuItem,
  SidebarProvider,
  SidebarTrigger,
} from "@/components/ui/sidebar"
```

```tsx
<SidebarProvider>
  <Sidebar>
    <SidebarContent>
      <SidebarMenu>
        <SidebarMenuItem>
          <SidebarMenuButton isActive>Calendar</SidebarMenuButton>
        </SidebarMenuItem>
      </SidebarMenu>
    </SidebarContent>
  </Sidebar>
  <SidebarInset>
    <SidebarTrigger />
  </SidebarInset>
</SidebarProvider>
```

Below 768px the sidebar opens as a sheet. Press <kbd>⌘</kbd> <kbd>B</kbd> (or <kbd>Ctrl</kbd> <kbd>B</kbd>) to toggle it.

### Streaming content

Page content can stream in under `<Suspense>` inside `SidebarProvider`. The provider's context never changes, so a boundary that is still streaming hydrates when the sidebar opens, closes or switches to the mobile sheet, instead of rendering a second copy on the client.
