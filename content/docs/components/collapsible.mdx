## Usage

```tsx
import {
  Collapsible,
  CollapsibleContent,
  CollapsibleTrigger,
} from "@/components/ui/collapsible"
```

```tsx
<Collapsible>
  <CollapsibleTrigger>Show more</CollapsibleTrigger>
  <CollapsibleContent>More bookings</CollapsibleContent>
</Collapsible>
```

Collapsible is unstyled. Use the `render` prop to make the trigger a `Button`.
