## Installation

There is no `DatePicker` component. A date picker is a `Popover` with a `Calendar` inside, so add the example you want and edit it:

<Installation name="date-picker-demo" />

## Composition

```text
Popover
├── PopoverTrigger
└── PopoverContent
    └── Calendar
```

Calendar reads the current date to mark today. In a Next.js app with `cacheComponents` enabled, render the picker inside `<Suspense>`. See [Calendar](/docs/components/calendar).
