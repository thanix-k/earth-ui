## Usage

```tsx
import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@/components/ui/dialog"
```

```tsx
<Dialog>
  <DialogTrigger>Open</DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Edit service</DialogTitle>
      <DialogDescription>Changes apply to new bookings.</DialogDescription>
    </DialogHeader>
  </DialogContent>
</Dialog>
```

The dialog is 640px wide and stays 16px from the edges of smaller screens. Pass a `max-w-*` class to `DialogContent` to change the width.

## Examples

### Close button in the footer

Set `showCloseButton={false}` on `DialogContent` to hide the corner close button, and `showCloseButton` on `DialogFooter` to add a Close button.

### Bottom sheet on phones

Set `isSheetOnPhone` on `DialogContent` to open a short dialog, such as a confirmation or a share link, as a bottom sheet below 768px. The popup's `data-layout` is `sheet` or `dialog`. Forms stay centred.
