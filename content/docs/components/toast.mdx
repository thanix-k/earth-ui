## Usage

Wrap your app in `Toaster` once.

```tsx
import { Toaster, toast } from "@/components/ui/toast"
```

```tsx
<Toaster>{children}</Toaster>
```

Then add toasts from anywhere.

```tsx
toast.add({ title: "Appointment booked", description: "Fri 7 Nov at 2:30 pm" })
```
