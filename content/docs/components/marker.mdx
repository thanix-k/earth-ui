## Usage

```tsx
import { Marker, MarkerContent, MarkerIcon } from "@/components/ui/marker"
```

```tsx
<Marker variant="separator">
  <MarkerContent>Today</MarkerContent>
</Marker>
```

`variant` is `default`, `separator` (a rule on each side) or `border` (a rule below). Use `render` to make the marker a link.
