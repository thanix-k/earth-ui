## Usage

Add the `Toaster` once, near the root of your app.

```tsx
import { Toaster } from "@/components/ui/sonner"
```

```tsx
<Toaster />
```

Then call `toast` from anywhere.

```tsx
import { toast } from "sonner"

toast("Appointment booked", { description: "Fri 7 Nov at 2:30 pm" })
```
