## Usage

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu"
```

```tsx
<DropdownMenu>
  <DropdownMenuTrigger>Open</DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuItem>Edit</DropdownMenuItem>
    <DropdownMenuItem>Reschedule</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

Items are 14px with more padding on touch screens, and 12px from the `lg` breakpoint. Use `variant="destructive"` for actions that delete or cancel.

Below 768px the menu opens as a bottom sheet over a dimmed page (`data-slot="dropdown-menu-backdrop"`), and its `data-layout` is `sheet` (`menu` otherwise). A submenu's sheet opens over its parent's. Pass `anchor` to `DropdownMenuContent` or `DropdownMenuSubContent` to position the popover against another element, such as the whole parent menu.
