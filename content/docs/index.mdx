Earth UI is the [Earth Design System](https://earth.anywhere.co) delivered as a [shadcn](https://ui.shadcn.com) registry. You install components with the shadcn CLI and own the source. They are stock shadcn components; Earth's look comes from shadcn's own CSS variables set to Earth values.

## What you get

- **Every shadcn component on Base UI.** Same APIs, parts and composition as shadcn's Base UI components, so shadcn docs, blocks and AI-generated code work as-is.
- **Earth values in shadcn's variables.** The `@earth-ui/base` item sets stock shadcn variables such as `--primary`, `--muted` and `--radius` to setmore-black values for light and dark mode, so any shadcn code looks like Earth.

## How it fits together

| Layer | Source |
| --- | --- |
| Behaviour and accessibility | [Base UI](https://base-ui.com) |
| Component API and composition | [shadcn](https://ui.shadcn.com) (Base UI flavour) |
| Colours and radius | Earth Design System (setmore-black) |
| Delivery | shadcn registry: `npx shadcn add @earth-ui/<component>` |
